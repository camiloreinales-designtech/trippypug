Trippy Pug gallery (lightweight)
================================
Upload everything in this folder (index.html + the images folder) to a static host
such as Netlify or GitHub Pages. Do not upload preview-only.html.

To add a painting: copy its photo into images/ (about 760 px on the long side) and
images/full/ (about 1800 px), then copy one <figure> block in index.html and edit the
title, year, size, price and alt text.
